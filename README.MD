# L04Boats(L08)

A brief description of the mobile application and its purpose.  
To display a catalog of boats for sale. Made improvements from the original L04Boats app.
As you can see from the first 2 images there was barely any styling and was all  just displayed fully. In the following
images is the improved version used StyleSheet to create boxes for each boat as well as used margins to
space out the texts and display the boats more nicely.
